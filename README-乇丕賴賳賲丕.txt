# خزانه امن شخصی – نسخه ۲

## استقرار PWA بدون Backend
1. تمام محتویات این پوشه را روی یک میزبان استاتیک با HTTPS منتشر کنید.
2. نشانی سایت را با Chrome اندروید باز کنید.
3. بار اول صفحه را آنلاین باز کنید تا Service Worker نصب و فایل‌های برنامه cache شوند.
4. از منوی Chrome گزینه Install app / افزودن به صفحه اصلی را انتخاب کنید.
5. پس از نصب و بارگذاری اولیه، پوسته برنامه به‌صورت آفلاین باز می‌شود.

این پروژه Backend و پایگاه داده ابری ندارد. IndexedDB به origin سایت وابسته است؛ اگر دامنه یا مرورگر را عوض کنید، داده‌های محلی خودکار منتقل نمی‌شوند. از فایل پشتیبان رمزنگاری‌شده استفاده کنید.

## اثر انگشت
دکمه فعال‌سازی از WebAuthn با افزونه PRF استفاده می‌کند تا کلید خزانه با خروجی وابسته به اعتبارنامه پلتفرم پوشانده شود. پشتیبانی PRF در همه دستگاه‌ها/مرورگرها تضمین نیست. پس از فعال‌سازی، ابتدا قفل کنید و ورود اثر انگشت را آزمایش کنید. رمز اصلی را نگه دارید و حذف نکنید.

## نکات امنیتی و محدودیت‌ها
- AES-256-GCM برای رمزنگاری داده‌ها و فایل‌ها استفاده شده است.
- مشتق‌سازی کلید فعلاً PBKDF2-HMAC-SHA-256 با ۶۰۰٬۰۰۰ تکرار است؛ Argon2id در این نسخه نیست.
- CVV2 اختیاری است، اما ذخیره آن ریسک امنیتی دارد و توصیه نمی‌شود.
- برنامه ممیزی امنیتی مستقل نشده است؛ ابتدا با داده آزمایشی تست شود.
- فایل‌های پیش‌نمایش هنگام مشاهده در حافظه مرورگر رمزگشایی می‌شوند. فایل دانلودشده خارج از خزانه دیگر رمزنگاری‌شده نیست.
- PWA باید روی HTTPS یا localhost سرو شود. بازکردن مستقیم فایل HTML از Downloads برای نصب PWA یا WebAuthn مناسب نیست.
- پشتیبان‌گیری دستی است؛ همگام‌سازی ابری خودکار وجود ندارد.

## پوشه‌بندی تصاویر و Private
- عکس‌ها و فایل‌ها پوشه دارند؛ پوشه Private به‌صورت پیش‌فرض وجود دارد.
- Private برای باز شدن به تأیید هویت دستگاه از WebAuthn و سپس رمز اختصاصی نیاز دارد.
- فایل‌های قرارگرفته در Private علاوه بر رمزنگاری اصلی خزانه، با کلید جداگانه مشتق‌شده از رمز Private نیز رمزنگاری می‌شوند.
- در مرورگر، تأیید WebAuthn ممکن است از اثر انگشت یا روش احراز هویت دستگاه استفاده کند؛ تضمین انتخاب صرفاً اثر انگشت از طریق وب ممکن نیست.


قابلیت انتقال امن (نسخه ۲.۲): در فرم افزودن فایل، گزینه «انتقال امن» را فعال و در مرورگرهای پشتیبانی‌شده پوشه مبدأ را انتخاب کن. برنامه ابتدا نسخه رمزنگاری‌شده را ذخیره می‌کند و سپس پس از تطبیق نام، حجم، زمان تغییر و نوع فایل و تأیید نهایی، برای حذف فایل اصلی اقدام می‌کند. اگر مرورگر یا مجوزها اجازه ندهند، فایل اصلی حذف نمی‌شود و باید دستی آن را حذف کنی. این قابلیت تضمین حذف از سطل زباله یا فضای ابری نمی‌دهد. ابتدا فقط با فایل آزمایشی امتحان کن.
